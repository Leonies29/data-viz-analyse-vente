# Data Visualization — Analyse des ventes

## Objectif du projet

Ce projet a pour objectif d’analyser les ventes d’un magasin à partir d’un jeu de données transactionnel.

L’analyse porte sur :
- les tendances commerciales ;
- les produits les plus performants ;
- les zones géographiques les plus rentables ;
- les habitudes d’achat des clients ;
- les canaux de vente.

## Partie faite par Améziane

la partie porte sur l’analyse des tendances commerciales.

J’ai donc analysé :
- le chiffre d’affaires total 
- la quantité totale vendue 
- le nombre de transactions 
- le prix moyen par unité 
- l’évolution mensuelle du chiffre d’affaires 
- l’évolution mensuelle des quantités vendues 
- le chiffre d’affaires par canal de vente 
- le chiffre d’affaires par catégorie.

L’objectif est de comprendre comment les ventes évoluent dans le temps et quels éléments peuvent expliquer les hausses ou les baisses de performance.
